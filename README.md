# gamepress

Point an AI at this repo and a game idea — it handles everything from idea to playable game, trailer, and store assets.

**Setup:** [gamepress setup guide](https://bparlette.github.io/gamepress/setup/) — what to install, what's optional, what each tool enables.

**AI agents:** read [`ORCHESTRATOR.md`](ORCHESTRATOR.md), then run `gamepress run`. That's the whole interface.
